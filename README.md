# Сайт Татьяны Бугаевой

Чистовая папка проекта.

## Структура

- `site/index.html` - локальная версия сайта, ее можно открыть в браузере.
- `site/assets/` - все картинки и визуальные файлы, которые использует сайт.
- `pdf/tanya-bugaeva-price-2026.pdf` - коммерческое предложение.
- `source-photos/` - исходные фотографии по проектам.
- `notes/` - вспомогательные материалы: варианты логотипа, шрифтов, листы согласования фото.

## Что открывать

Для просмотра сайта откройте:

`site/index.html`

Для просмотра коммерческого предложения откройте:

`pdf/tanya-bugaeva-price-2026.pdf`

## Важно

Эта папка - чистовая копия. Рабочие технические файлы Codex остались в старой папке и не нужны для обычного просмотра.

## GitHub Pages

Для публикации через GitHub Pages используется папка `site/`.

В репозитории есть workflow:

`/.github/workflows/pages.yml`

После push в ветку `main` GitHub Actions загрузит папку `site/` и опубликует ее через GitHub Pages.

Исходные фотографии из `source-photos/` не коммитятся в GitHub. Они остаются локально как архив. На сайте используются оптимизированные файлы из `site/assets/`.
